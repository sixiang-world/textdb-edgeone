📡 API 接口
POST /update/ 创建 / 更新 / 删除
GET /{key} 读取文本数据
POST /{key} 直接写入（简写）
DELETE /{key} 删除数据
参数必填说明
key必填文本标识，6-60 位，仅 0-9a-zA-Z-_
value—文本数据，最大 20 万字符。留空则删除

ℹ️ 说明
  • 读取不限次数，每个 IP 每日写入/删除操作限 500 次
  • 数据无密码保护，建议使用 20 位以上随机 Key
  • 1 年未更新的记录会自动删除
  • 全程支持 CORS 跨域请求
  • 响应 Content-Type 为 text/plain
