# TextDB EdgeOne v1.3.0 — 实施计划

> **配套设计规格：** `docs/superpowers/specs/2026-09-04-v1.3.0-design.md`
> **Goal:** 实现 4 个功能：OpenAPI 文档、本地 Key 浏览、写入队列/重试、Markdown 增强
> **Architecture:** 4 个 Phase 按风险从低到高推进，每个 Phase 独立可验证。全部为前端改动，Edge Function 不变。
> **Tech Stack:** React 19 + TypeScript + Tailwind v4 + shadcn/ui + idb + react-markdown 插件 + swagger-ui-react
> **状态：** 全部完成，lint + typecheck 通过，已打 tag v1.3.0

## Phase 3：写入队列/重试（改动写入路径，重点测试）✅ 完成

### Task 3.1：writeQueue 工具库

- [x] `npm install idb`（自带类型）
- [x] 创建 `src/lib/writeQueue.ts`
- [x] 定义 `QueueItem` 接口和 `QueueItemStatus` 类型（pending/processing/error，无 done——成功即删除）
- [x] 用 `idb.openDB('textdb', 1)` 创建数据库，upgrade 时建 `write-queue` store（keyPath: id）
- [x] 实现 `enqueue(input, opts?)`：**async**，生成 uuid，status=pending，`await db.add()`，失败降级 `fallbackEnqueue`；触发 `processQueue()`
- [x] 实现 `processQueue()`：串行取 pending 项，调用对应 API（writeData/deleteData/uploadFile）
- [x] 成功：从 DB 删除，触发成功回调（toast + recordKey + onStatsRefresh + history refresh）
- [x] 失败：retryCount++，指数退避（1s/2s/4s），setTimeout 重试；超 `MAX_RETRIES=3` 次 status=error，存 lastError，触发 onError
- [x] 实现 `retryItem(id)`：status 改回 pending，触发处理
- [x] 实现 `discardItem(id)`：从 DB 删除
- [x] 实现 `retryAll()`：所有 error 项改回 pending
- [x] 实现 `initQueue(callbacks)`：页面加载时扫描 pending/processing 项重新处理；监听 `online` 事件（`onlineListenerRegistered` 防重复）
- [x] 实现订阅机制：`subscribe(callback)` 返回取消函数
- [x] 导出 `MAX_RETRIES` 常量
- [x] IndexedDB 不可用时 `fallbackEnqueue` 降级为直接调用 API

### Task 3.2：QueueStatus 组件

- [x] 创建 `src/components/QueueStatus.tsx`
- [x] 订阅 writeQueue 的状态变化
- [x] 浮动指示器（右下角）：pending > 0 显示旋转图标+数字；error > 0 显示红色徽章+数字
- [x] 点击展开面板：队列列表（key、type 图标、status、retryCount `{n}/{MAX_RETRIES}`、lastError）
- [x] error 项："重试"按钮 → retryItem；"丢弃"按钮 → discardItem
- [x] 底部"全部重试"按钮
- [x] 队列为空时隐藏指示器

## 风险与回退

| 风险 | 影响 | 回退方案 | 状态 |
|---|---|---|---|
| swagger-ui-react 体积大（~100KB） | 首屏加载变慢 | 改为 React.lazy 动态导入 ApiDocs 页 | 已接受，后续优化 |
| idb 在某些浏览器不支持 | 队列功能不可用 | 已设计降级为直接 fetch | ✅ 已实现 |
| Markdown 插件冲突 | 渲染异常 | 逐个插件启用，二分定位 | ✅ 无冲突 |
| 写入队列改变交互习惯 | 用户困惑 | 保留 toast 反馈，队列指示器清晰 | ✅ 已验证 |
| IndexedDB 存密码明文 | 共享电脑风险 | 文档注明，后续 E2EE 时处理 | 已接受 |
| Mermaid ref=null 卡住 loading | 图表不渲染 | 改用 useState 存 svg | ✅ 已修复 |
| FolderUpload 进度条一闪即逝 | 用户看不到进度 | checkDone() 回调中重置 | ✅ 已修复 |
| WriteCard 按钮可重复点击 | 重复入队 | isSubmitting 状态 + 守卫 | ✅ 已修复 |
